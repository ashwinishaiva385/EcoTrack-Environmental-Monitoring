# 🌱 EcoTrack AI – Waste Monitoring System

EcoTrack AI is a web-based project developed to report illegal waste dumping and monitor environmental incidents.

## Technologies Used
- Java 21
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Git & GitHub

## Features
- Report waste dumping incidents.
- Select waste categories.
- Detect location using GPS.
- Upload waste photographs.
- Store incident details in MySQL.
- View recent incidents.
- Track incident status.

## What I Learned
- Java Spring Boot development.
- Creating REST APIs.
- Connecting Spring Boot with MySQL.
- Database operations using JPA.
- Frontend and backend integration.
- Image upload handling.
- GPS location detection.
- Using Git and GitHub.

## Future Enhancements
